# Currency-Converting-Website
A responsive Currency Converter web application built using **HTML, CSS, and JavaScript**. It allows users to convert currencies between countries using real-time exchange rates fetched from the Fawaz Ahmed Currency API.

## Features

 Convert between multiple international currencies
- Real-time exchange rates
- Automatic country flag updates based on selected currencies
- Responsive and modern user interface
- Fast currency conversion with a single click
- Clean and user-friendly design

## Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)
- Fawaz Ahmed Currency API
- FlagsAPI
- Font Awesome

##  API Used

* Exchange Rates: https://github.com/fawazahmed0/exchange-api
* Country Flags: https://flagsapi.com/
